# Виды оболочек
## Profile shell
Входящая оболочка - это первая оболочка, которую пользователь получает после успешного входа в систему (через SSH, физический терминал, консоль). Она инициализирует сессию пользователя.
Обычно это файл `/etc/profile`, `~/.profile`, `~/.bash_profile` или `~/.bash_login`.
## Interactive shell
Интерактивная оболочка ждет ввода команд от пользователя и выводит приглашение (prompt).
Файл: `~/.bashrc` или `/etc/bash.bashrc`
## Noniteractive shell
Оболочка, которая просто выполняет скрипт. Она не является интерактивной, не подключает интерактивные конфиги, однако использует переменную окружения `BASH_ENV`.
## Частые проблемы с SSH
Самая частая проблема новичков: добавление экспорта переменной в `~/.bashrc`. Однако он не работает при входе по SSH. Это происходит потому, что SSH-сессия — это **login shell**, которая считывает `~/.profile`.
Решение простое: производить изменения в `~/.profile`, либо включить в него файл `~/.bashrc`.
## Команды управления процессами
## `nohup`
Пример:
```bash
nohup sudo -EH app & 
```
## `disown`
Если мы хотим сделать работающий в терминале процесс бэкграундным, то останавливаем через `ctrl+Z`. Далее выполняем `bg`. После чего отвязываем его от терминала:
```bash
disown -h %1
```
где %1 - идентификатор (номер) задачи в текущем шеле.
Флаг `-h` гарантирует, что при закрытии терминала не будет посылаться сигнал `SIGHUP` (hangup).
